Paslago

Envoyez fichiers et textes directement aux appareils proches. Sans internet, compte ni câble.

Assistance

Un appareil n’apparaît pas

Vérifiez que les deux appareils sont sur le même Wi-Fi, que Paslago est ouvert sur chacun et que l’accès au réseau local est autorisé. Les réseaux invités peuvent isoler les appareils. Sinon, utilisez + pour vous connecter par adresse IP.

L’envoi ne démarre pas

Si l’autre appareil est verrouillé, déverrouillez-le et affichez Paslago. Sous Windows, vérifiez que le pare-feu autorise Paslago sur les réseaux privés ; le port par défaut est 47321.

Où sont enregistrés les fichiers ?

Sur Mac et Windows, dans le dossier Paslago de Téléchargements. Sur iPhone et iPad, dans le dossier Paslago de l’app Fichiers. Sur Android, dans le dossier de l’application ; le bouton de partage du transfert permet de les enregistrer ailleurs.

Un iPhone verrouillé peut-il recevoir ?

Paslago doit être ouvert à l’écran pour recevoir une nouvelle demande. Un transfert commencé peut continuer en arrière-plan à partir d’iOS 26.

Comment se connecter sans box ?

Ouvrez Se connecter sans box. Android ou Windows peut ouvrir un réseau temporaire et l’autre appareil scanne le code. iPhone, iPad et Mac se trouvent tout seuls quand le Wi-Fi est activé.
